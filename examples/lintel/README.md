# Lintel

Lintel is a shared inbox for small property management firms. Tenant email, SMS and web form messages arrive in one inbox. Staff assign a message to a teammate, tag it, and turn a maintenance request into a work order for a vendor.

- Customers: property management firms with 50 to 500 rental units and 3 to 15 staff.
- Price: $39 per staff user per month.
- Launched September 2025. 62 paying firms in October 2026.

This is a fictional product, used as the ProductOS example. Start with `product/PRODUCT.md`. `RUNS.md` says how the `product/` folder was made.
